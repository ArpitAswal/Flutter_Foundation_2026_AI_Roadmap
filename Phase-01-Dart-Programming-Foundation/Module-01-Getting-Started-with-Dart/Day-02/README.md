# 📘Day 2 — Variables, Data Types, Type Inference & Null Safety

## Overview

This lesson introduces the core building blocks of the Dart language. It explains how data is stored, how the compiler infers types, and how Dart's null safety system helps prevent runtime errors.

## Learning Objectives

After completing this lesson, you should be able to:

- Declare variables correctly.
- Choose the appropriate data type.
- Understand the differences between `var`, `dynamic`, and `Object`.
- Use `final`, `const`, and `late` appropriately.
- Apply null safety confidently.
- Convert values safely between data types.
- Write cleaner and more maintainable Dart code.

## Common Mistakes

- Confusing `var` with `dynamic`.
- Overusing `dynamic`.
- Using `const` for runtime values.
- Overusing nullable variables.
- Using the null assertion operator (`!`) unnecessarily.
- Choosing poor variable names.
